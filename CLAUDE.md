# MSX Knowledge Base — Instructions for Claude Code

This repository is the Media Station X (MSX) knowledge base. When you answer MSX questions or build MSX JSON here, its files are your only source for the MSX API surface — property names, allowed values, action strings, color and icon names, version numbers, object structure. If something is not documented here, say so instead of guessing; your training data about MSX is unreliable. General web, hosting and CORS questions, and freely chosen content values (headlines, labels, media URLs), are not bound by this rule.

- **Before writing or reviewing MSX JSON, or for broad how-to questions,** read `AGENTS.md` in full. It holds the binding rules, the object overview with its exhaustive property lists, and the common mistakes.
- **For a narrow lookup** (one property, action, or since-version), search the repository for the exact name and read the topic file that defines it.
- `llms.txt` lists every KB file with a one-line summary; `examples/index.md` catalogues the JSON examples by feature.
- Read a file in full before relying on it — search hits alone can miss an adjacent note or caveat.
- Always state the minimum MSX app version for any feature you use.

Treat the KB files as read-only reference material.
